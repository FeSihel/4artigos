# 4Artigos 🎓

Buscador de artigos acadêmicos reais para TCC, projetado para retornar referências diretas sem alucinações de inteligência artificial.

## 💡 Sobre o Projeto
Muitos estudantes enfrentam dificuldades ao buscar referências bibliográficas para trabalhos acadêmicos e TCCs utilizando chatbots de IA, que frequentemente inventam títulos, autores e links de DOI inexistentes. 

O **4Artigos** resolve isso fazendo buscas diretas e determinísticas em bases de dados acadêmicas abertas, garantindo que o usuário receba apenas artigos que realmente existem, limitados a 4 resultados por consulta para facilitar o início da pesquisa.

## 🚀 Tecnologias
- **Frontend:** HTML5, CSS3 e Vanilla JavaScript em um único arquivo (`index.html`).
- **Dados:** [OpenAlex API](https://openalex.org/) (API pública e gratuita, sem necessidade de chaves de acesso).
- **Recursos:** Links diretos para DOI/OpenAlex e botão de copiar citação formatada.
